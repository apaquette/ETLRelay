# Security Policy

## Supported versions

ETLRelay is experimental pre-1.0 software. Security reports will be assessed against the latest released version. Fixes or backports for older releases are not guaranteed unless maintainers explicitly announce otherwise. This policy may change as the project matures.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues, pull requests, or discussions.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository (Security → Report a vulnerability). If it is unavailable, contact the maintainers through a verified private channel and confirm the disclosure process before sending sensitive technical details. Do not assume a private reporting channel is enabled without checking the repository's current settings.

Include the affected version or commit, a description of the potential impact, and enough information to reproduce the issue safely. Do not include real credentials, private datasets, production records, or other sensitive information in the report.

## Scope and expectations

ETLRelay is pre-1.0 software and is not yet presented as a security-hardened or production-certified platform. Evaluate it in a non-production environment before using it to process important or sensitive data. Reports will be acknowledged and assessed as promptly as reasonably possible; no fixed response or remediation SLA is promised.

The repository owner should verify the private reporting configuration and the published reporting instructions as part of release maintenance.
