# Security Policy

## Supported versions

ETLRelay is pre-1.0 software. During the initial release series, security fixes will be considered for the latest `0.1.x` release. Support and backport commitments may change as the project matures.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues or discussions.

Use the repository's private vulnerability reporting feature on GitHub (Security → Report a vulnerability) to contact the maintainers privately. The repository owner should enable private vulnerability reporting before the first public release. If that feature is unavailable, contact the maintainers privately and agree on a disclosure process before sharing technical details publicly.

Please include the affected version or commit, a description of the impact, and enough information to reproduce the issue safely. Do not include real credentials, private datasets, or other sensitive information in the report.

## Scope and expectations

ETLRelay is experimental pre-1.0 software. Users should validate it in a non-production environment before processing important or sensitive data. A security report will be acknowledged and assessed as promptly as reasonably possible; no fixed response or remediation SLA is promised for this initial release.
