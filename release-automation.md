# CI and Release Automation

The maintained procedure is [CI and Release Automation](docs/development/release-automation.md).
It documents branch promotion, metadata/version preparation, quality checks,
wheel and source-distribution verification, TestPyPI rehearsal, production gates,
and versioned documentation deployment.

Use [RELEASE_CHECKS.md](RELEASE_CHECKS.md) for release evidence. The current
v0.9.0 notes are the finalized [release notes](docs/development/release-notes-v0.9.0.md).
Do not publish or reuse a previously published version to apply development fixes.
